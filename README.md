# ClickFix Professional Front-End

## What's included
- Login / sign-up entry screen with customer and worker roles
- Mobile-friendly home page with popular services
- Top-right settings and ClickFix brand mark
- Bottom navigation: Home, Search, Cart, Profile
- Search/filter for services, add-to-cart, demo booking list, profile, settings
- Responsive CSS for mobile and desktop

## Publish to your existing GitHub Pages site
1. Download and extract this ZIP.
2. Open the extracted folder.
3. Upload the files inside it to the **root** of your existing GitHub repository.
4. Keep your existing `logo.png.jpeg` file if you want to use it elsewhere; this design uses a text/icon brand mark by default.
5. Commit changes and wait for GitHub Pages to deploy.

## Important demo limitation
This is a front-end prototype. Login/signup are not secure authentication, and user/cart/booking data is saved only in the current browser using localStorage. Do not use real passwords or sensitive customer data. A production website needs a secure authentication provider/backend, database, server-side authorization, and a worker verification/admin process.
